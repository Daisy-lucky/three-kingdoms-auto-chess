## 📖 游戏简介

**三国自走棋 (Three Kingdoms Auto Chess)** 是一款以三国为背景的自走棋游戏。玩家扮演一方诸侯，招募三国名将，搭配阵容羁绊，合成武器装备，与其他玩家进行自动对战！

## 🎮 操作说明

### 基本流程
1. **准备阶段 (30 秒)**
   - 购买武将（点击商店）
   - 放置武将（点击棋盘下方绿色区域）
   - 合成装备
   - 调整站位

2. **战斗阶段**
   - 点击"开始战斗"
   - 自动进行对战
   - 胜者获得金币奖励

3. **结算阶段**
   - 获得金币（基础 5+ 胜利 2+ 利息）
   - 刷新商店
   - 准备下一回合

### 快捷键
| 按键 | 功能 |
|------|------|
| 鼠标左键 | 选择/放置武将 |
| 鼠标右键 | 取消选择 |
| R 键 | 刷新商店 |
| E 键 | 购买经验 |
| 空格键 | 开始战斗 |

## 🏆 游戏模式

### 排位模式
- 8 人对战
- 最后存活者获胜
- 段位系统：青铜→白银→黄金→铂金→钻石→大师→王者

### PVE 模式
- 野怪回合：1-5、10、15、20...
- 击败野怪获得装备
- BOSS 回合：10、20、30...
